## Relational / Modeling

- **Ertragswertverfahren** (§§ 27–34 ImmoWertV) is the method for which these Liegenschaftszinssätze are the discount-rate input — directly usable for a compensation/valuation model's income-capitalization leg.
- **Liegenschaftszinssatz regression formula** (multiple linear regression, IBM SPSS):
  For Gebietsgruppen Südost/Südwest/Nord:
  `Liegenschaftszinssatz(31.12.2024) = 0,644 + 0,132 × Objektmiete[EUR/m²/Monat] + 0,0013304 × 1.096`
  (1.096 = Tage von 01.01.2022 bis 31.12.2024, i.e. the time-trend term is fixed at the reporting date)
  For Gebietsgruppen City/Ost/West: same formula **+ 0,167** location offset.
  → Only valid within the 5%–95% percentile range of Objektmiete (~6–20 EUR/m²/Monat per Tab. 6–11).
- Full applied rate = base formula value **+ Baujahres-Korrektur + Gewerbeanteil-Korrektur (+0,08 per 10pp) + Altbezirk-Korrektur** (additive corrections, see Data section).
- Kaufpreis-Multiplikator (Vervielfältiger) ≈ 26,6× Nettojahresrohertrag on average — a cross-check/reasonableness anchor for a capitalization-based valuation independent of the regression.
- Bewirtschaftungskosten formula components (all subtracted from Jahresrohertrag to get Jahresreinertrag, the numerator of the Ertragswertverfahren):
  `Jahresreinertrag = Jahresrohertrag − Instandhaltungskosten − Verwaltungskosten − Mietausfallwagnis (− Bodenwertverzinsung, not in this doc)`
- RND feeds the capitalization annuity factor (Vervielfältiger table per ImmoWertV, not itself reproduced here — would need §§ 27–34 ImmoWertV annex) — RND itself is a function of Baujahr × Bauzustand (± modernization corrections).
- Note: this is **market valuation methodology** (Verkehrswert), not the Article 15 compensation formula itself — but it is very likely the technical basis a Verkehrswert-anchored or partial-Verkehrswert compensation scheme (as opposed to a book-value/Einheitswert scheme) would use as its discount-rate and cost-parameter input.
